# Changelog – eKofini@Proper Website

This changelog records the development, improvements, testing and updates made to the eKofini@Proper website.

## Version 1.0 – Website Development

### 1. Website Pages

* Created the homepage (`index.html`).
* Created the About Us page (`about.html`).
* Created the Services page (`services.html`).
* Created the Enquiry page (`enquiry.html`).
* Created the Contact Us page (`contact us.html`).

### 2. Website Design

* Developed a coffee-inspired colour scheme using cream, brown and dark brown.
* Added images to improve the website's appearance.
* Created a navigation menu to help visitors move between pages.
* Used CSS to style the website.
* Added a consistent layout and branding across the website.

### 3. Interactive Features

* Added a search feature to the homepage.
* Added an interactive FAQ section to the Services page.
* Added a photo gallery with a lightbox feature.
* Included contact and enquiry forms.
* Added form validation and response messages.
* Included links to Instagram and Google Maps.

### 4. Search Engine Optimisation (SEO)

* Added appropriate page titles to all five website pages.
* Added meta descriptions and keywords where applicable.
* Included viewport settings to support mobile devices.
* Improved image alternative text (alt text).
* Used appropriate headings and page descriptions.

### 5. Responsive Design and Testing

* Tested the website on mobile device screen sizes.
* Tested the website on tablet screen sizes.
* Checked navigation links between all five pages.
* Checked that website images display correctly.
* Tested the gallery, FAQ section and forms.
* Corrected errors identified during testing.

### 6. Documentation

* Created and updated the `README.md` file.
* Created this `CHANGELOG.md` file to document website development.

### 7. Version Control

* Used Git and GitHub to track project changes.
* Created commits to record development improvements.
* Pushed updated website files to the GitHub repository.

## Future Improvements

* Connect the contact and enquiry forms to a backend service so that customer submissions can be stored and delivered.
* Continue improving website content and accessibility.
* Monitor website performance and user experience.
* Update website information and images when necessary.
