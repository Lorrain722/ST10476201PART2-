# eKofini@Proper Website

## 1. Project Overview

The eKofini@Proper website is a web development project created to improve the online presence of a locally owned coffee shop serving the Ekangala community. The website provides information about the coffee shop, its services, food and drinks, and ways for customers to make enquiries and contact the business.

The website aims to provide visitors with an attractive, user-friendly experience while making important information easy to find.

## 2. Project Objectives

The main objectives of the website are to:

* Improve the online presence of eKofini@Proper.
* Provide information about the coffee shop and its services.
* Display information about available food and drinks.
* Allow customers to make enquiries.
* Provide contact information for customers.
* Create a simple and easy-to-navigate website.
* Use interactive features to improve the user experience.

## 3. Website Pages

The website contains the following pages:

* **Home (`index.html`):** Introduces the coffee shop and provides an overview of its offerings.
* **About Us (`about.html`):** Provides information about the business.
* **Services (`services.html`):** Presents the services and offerings available at the coffee shop.
* **Enquiry (`enquiry.html`):** Allows visitors to submit enquiries through a form.
* **Contact Us (`contact us.html`):** Provides information for customers who want to contact the business.

## 4. Technologies Used

The project uses the following technologies:

* **HTML5:** Structures the content and pages of the website.
* **CSS3:** Controls the layout, colours, fonts and overall appearance.
* **JavaScript:** Adds interactive functionality, including website search and other interactive features where implemented.
* **Visual Studio Code:** Used to write and edit the website code.
* **GitHub:** Used for version control and project storage, where configured.

## 5. Design and User Experience

The website uses a coffee-inspired colour scheme, including cream, brown and dark brown. These colours help create a warm appearance that suits the coffee shop's identity.

The website is designed to make navigation simple and to help visitors find information about the business, services, enquiries and contact details.

Images are used to support the website's visual presentation.

## 6. Interactive Features

The project includes or is intended to include interactive features such as:

* A website search feature.
* An interactive FAQ section.
* An image gallery with a lightbox.
* Enquiry and contact forms.
* An interactive map, if implemented.

The availability and functionality of each feature depend on the final website implementation.

## 8. How to Run the Website

1. Download or clone the project files from GitHub, if the project has been uploaded.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Open the page in a web browser or use the Live Server extension in Visual Studio Code.
5. Use the navigation menu to visit the other pages.

## 9. Testing

The website should be tested to ensure that:

* All navigation links open the correct pages.
* Images display correctly.
* The layout works on different screen sizes.
* Interactive features work as expected.
* Forms validate the information entered by users.
* All pages load without errors.
